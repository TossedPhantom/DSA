# DSA

A collection of Data Structures and Algorithms implemented mostly in C.

## Building

Compile `.c` files using this command in your terminal:
```
gcc source_file.c -o source_file
```

For `.cpp` files, use `g++` instead of `gcc`. For example:
```
g++ source_file.cpp -o source_file
```

## Platform

Developed & Tested on Arch Linux. Should work on other Unix-like systems.
